# Money value object поверх Decimal

## Контекст

Приложение работает с финансовыми суммами. Использование `Double` для доменной арифметики денег запрещено правилами проекта.

## Решение

Использовать `Money` value object поверх `Decimal`.

`Money` хранит:

- `amount: Decimal`;
- `currencyCode: String`.

## Последствия

Плюсы:

- безопаснее для финансовых расчетов, чем `Double`;
- валюта и арифметические правила централизованы;
- проще запретить смешивание валют;
- остается путь к будущему расширению без включения мультивалютности в MVP.

Минусы:

- нужен mapping в SwiftData;
- нужно явно определить rounding/formatting policy;
- больше кода, чем при использовании чистого `Decimal`.

## Альтернативы

- Только `Decimal`: проще, но правила валюты и округления расползутся.
- Integer minor units: очень надежно, но сложнее для MVP и требует отдельной политики валютных minor units.

## Проверка решения

Решение остается валидным, пока:

- MVP использует одну основную валюту;
- финансовая точность важнее минимального количества кода;
- нет отдельного требования на multi-currency accounting.
