## Контекст

MVP — локальное iPhone-first приложение для учета семейных доходов и кредитной нагрузки. Внешние интеграции, синхронизация, импорт/экспорт и мультивалютность не входят в первую версию.

## Решение

Использовать:

- iOS 17+ как минимальную версию;
- SwiftUI для UI;
- SwiftData для локального хранения.

## Последствия

Плюсы:

- современный Apple stack;
- меньше boilerplate по сравнению с Core Data;
- хорошо подходит для локального MVP с формами, списками и связями;
- проще стартовать без внешних зависимостей.

Минусы:

- приложение не поддерживает iOS 16 и ниже;
- SwiftData требует аккуратного отношения к миграциям и типам данных;
- для финансового ядра нельзя полагаться на persistence-модели как на domain-модели.

## Альтернативы

- iOS 16+ + Core Data: шире поддержка устройств, но больше complexity.
- iOS 17+ + Core Data: зрелое хранилище, но менее простой MVP-start.

## Проверка решения

Решение остается валидным, пока:

- MVP остается локальным;
- нет требования поддержки iOS 16;
- нет сложной синхронизации или cloud conflict resolution.
