## 1. Цель

Документ фиксирует состав MVP-фич до разложения на tasks. Он не является backlog implementation tasks и не разрешает писать feature-код без отдельных task-документов.

## 2. Feature map

| Фича | Spec | Ценность |
| --- | --- | --- |
| Первый запуск и настройки валюты | `onboarding-settings.md` | Пользователь задает базовые параметры локального приложения. |
| Участники семьи | `family-members.md` | Семейный бюджет разделяется по людям. |
| Доходы | `income-management.md` | Пользователь фиксирует регулярные и разовые доходы. |
| Кредиты и рассрочки | `credits-installments.md` | Пользователь создает кредиты и получает график платежей. |
| Годовая таблица | `yearly-overview.md` | Пользователь видит финансовую нагрузку по году. |
| Детали месяца и оплата платежей | `month-details-payments.md` | Пользователь понимает состав месяца и отмечает оплату. |
| Защита приложения | `app-security.md` | Финансовые данные защищаются Face ID / Touch ID. |
| Локальные напоминания | `local-payment-reminders.md` | Пользователь получает нейтральные напоминания о платежах. |

## 3. Рекомендуемый порядок реализации

1. Первый запуск и настройки валюты.
2. Участники семьи.
3. Доходы.
4. Кредиты и рассрочки.
5. Годовая таблица.
6. Детали месяца и оплата платежей.
7. Защита приложения.
8. Локальные напоминания.

Порядок выбран так, чтобы сначала появилась модель данных и доменная база, затем финансовые расчеты, затем основные экраны, затем privacy/system capabilities.

## 4. Cross-feature dependencies

- Доходы зависят от участников семьи.
- Кредиты и рассрочки зависят от участников семьи.
- Годовая таблица зависит от участников, доходов, кредитов и domain calculations.
- Детали месяца зависят от годовой таблицы и кредитов.
- Защита приложения зависит от настроек.
- Локальные напоминания зависят от кредитов и настроек.

## 5. Out of scope для всего MVP

- банковские интеграции;
- импорт/экспорт;
- iCloud sync;
- совместная работа между Apple ID;
- мультивалютность;
- учет ежедневных расходов;
- сложная аналитика;
- веб-версия;
- Android-версия.
